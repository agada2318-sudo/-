# CODEMATE — AI 코드 해설 및 바이브 코딩 튜터

> AI에게 코딩을 맡긴 초보 개발자가, 받은 코드를 **한 줄씩 이해하고** 실행 흐름과 안전성까지 확인할 수 있게 돕는 코드 해설 서비스

**배포 주소: https://codemate-psi.vercel.app**

---

## 서비스 소개

AI 덕분에 코딩을 몰라도 앱이나 웹사이트를 만들 수 있게 됐지만, 오류가 났을 때 어디가 잘못됐는지, 이 코드가 왜 있는지 모른 채 넘어가는 일이 많아요. 코딩 수업을 듣는 대학생도 마찬가지예요. 놓친 내용이나 이해하지 못한 과제 코드를 교수님께 일일이 물어보기도 어렵습니다.

CODEMATE는 사용자를 **초급자 · 중급자 · 전공자** 세 단계로 나누고, 같은 코드라도 수준에 맞는 관점으로 해설해 줍니다.

| 수준 | 대상 | 설명 방식 |
|---|---|---|
| 초급자 | 코딩을 처음 배우는 비전공자 | "이 코드가 무엇인가". 전문 용어 없이 일상 비유와 화면에 보이는 모습 중심 |
| 중급자 | 기초 문법을 아는 주니어 | "어떻게 작동하는가". 처리 순서, 값의 흐름, 줄 사이의 연결 |
| 전공자 | 현업 개발자 · CS 전공자 | "내부 동작과 결함". 스펙, 성능, 보안, 접근성 관점의 분석 |

## 주요 기능

- **수준별 맞춤 해설:** 같은 줄이라도 초급자 · 중급자 · 전공자에게 서로 다른 내용과 말투로 설명해요.
- **한 줄씩 자세히 해설:** 코드를 줄 단위로 뜯어서 설명해요. 초급 모드에서는 코드 정의, 이 줄의 의미, 여기서 쓰인 이유를 보여주고, 태그와 속성, 키워드의 뜻풀이(사전)도 제공해요.
- **오류 감지와 설명:** 괄호나 태그가 닫히지 않는 문법 오류와 오타를 찾아 빨간 줄로 표시해요. 오류 줄을 눌러 가며 다음 오류로 바로 이동할 수 있고, 오류가 있는 줄에는 모범 코드를 보여줘요.
- **더 나은 코드 제안:** 중급자에게는 리팩토링 추천과 더 추가하면 좋을 코드를, 전공자에게는 버그 · 보안 점검, 누락 요소 진단(접근성 · 예외 처리 등), 추천 패치 코드를 보여줘요.
- **여러 파일 해석:** 파일을 여러 개 불러와서 파일 탭으로 오가며 해석할 수 있어요.
- **예시 코드 내장:** HTML, 로그인 폼, JavaScript, 결제 화면, React 훅, CSS 예시가 들어 있어서 바로 체험해 볼 수 있어요.
- **코드 복사:** 해설이 달린 코드나 추천 코드를 복사할 수 있어요.

## AI 동작 방식

해석 요청은 브라우저가 아니라 **서버**에서 AI를 호출해요. API 키는 서버 환경변수에만 있고 브라우저로 나가지 않아요.

1. `OPENAI_API_KEY`가 있으면 **OpenAI**(기본 모델 `gpt-5.4-mini`)를 사용해요.
2. 없으면 `GEMINI_API_KEY`로 **Google Gemini**를 사용해요.
3. 둘 다 없거나 호출에 실패하면 **내장 규칙 분석기**로 대신 해설해서, 화면은 항상 동작해요.

서버는 한 번에 보낼 수 있는 코드 길이를 **20,000자**로 제한해요.

## 기술 스택

- 프론트엔드: React 19, TypeScript, Vite, Tailwind CSS
- 서버: Node.js, Express(로컬 개발), Vercel 서버리스 함수(배포)
- AI: OpenAI API, Google Gemini API

## 로컬에서 실행하기

```bash
npm install
npm run dev                  # http://localhost:3000
```

키를 쓰려면 프로젝트 폴더에 `.env.local` 파일을 만들고, **가지고 있는 키만** 적어 주세요. (`.env.example`을 그대로 복사하면 견본 글자가 키로 들어가서 AI가 동작하지 않아요.)

```
OPENAI_API_KEY=내_키
```

| 환경변수 | 설명 |
|---|---|
| `OPENAI_API_KEY` | OpenAI 키. 있으면 OpenAI를 우선 사용해요. |
| `OPENAI_MODEL` | 사용할 모델 이름이에요. 기본값은 `gpt-5.4-mini`예요. |
| `GEMINI_API_KEY` | Gemini 키. OpenAI 키가 없을 때 사용해요. |

키가 하나도 없어도 내장 분석기로 실행돼요. `.env`와 `.env.local`은 `.gitignore`에 들어 있어서 GitHub에 올라가지 않아요.

## 배포 (Vercel)

화면은 정적 파일로 빌드하고, AI 호출은 서버리스 함수(`api/analyze-code.ts`)가 맡아요.

```bash
npm i -g vercel
vercel login
vercel env add OPENAI_API_KEY production   # 키는 Vercel 환경변수에만 넣기
vercel deploy --prod
```

## 폴더 구조

```
├─ src/
│  ├─ App.tsx              # 화면
│  ├─ utils/               # 내장 분석기 (구문 검사, 수준별 설명 생성)
│  ├─ data/presets.ts      # 예시 코드
│  └─ server/analyze.ts    # AI 호출 공용 로직 (로컬 서버와 Vercel 함수가 같이 사용)
├─ api/analyze-code.ts     # Vercel 서버리스 함수: POST /api/analyze-code
├─ server.ts               # 로컬 개발용 Express 서버
├─ codemate/               # Claude API 기반 경량 버전 (별도 실행)
└─ vercel.json             # 배포 설정
```

AI 호출 방식이나 프롬프트를 바꾸려면 `src/server/analyze.ts`를 고치면 돼요.
